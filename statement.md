# Project Statement

## Project Title

Student Performance Management System

## Problem Statement

Educational institutions need an organized way to maintain student information
and manage academic performance records. Manual management of student details
and marks can make searching, updating, calculating results, and generating
reports difficult.

The Student Performance Management System is a Java-based command-line
application designed to manage student information and academic performance
efficiently.

## Scope of the Project

The system provides functionality for:

- Student registration and management
- Searching and updating student information
- Recording academic performance
- Calculating total and average marks
- Assigning grades
- Generating student performance reports
- Generating overall performance statistics
- Storing data using files

## Target Users

The primary users of the system are:

- Teachers
- Faculty members
- Academic administrators
- Students for basic performance record management

## High-Level Features

1. Student Management
2. Performance Management
3. Search and Update Operations
4. Performance Calculation
5. Grade Calculation
6. Student Reports
7. Overall Analytics
8. File-Based Data Storage
9. Input Validation
10. Error Handling

## Technology

- Java
- Object-Oriented Programming

- Exception Handling
- Command-Line Interface
